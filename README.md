# 人間乱数検定 (ningen-ransu)

「ランダムに」表/裏を200回押してもらい、あなたの乱数が本物の乱数とどこが違うかを検定で暴くWebアプリ。

公開: https://ningen-ransu.vercel.app

## しくみ

- **予測器**(`src/lib/predictor.js`): 直近0〜6手の表裏・直近1〜5回の「変えた/続けた」を文脈にした n-gram 予測を、ベイズ混合+fixed-share で束ねる文脈混合。各手の予測は**押す前に封をし**、結果画面で列全体から再計算した予測と完全一致することを確かめて表示する。
- **検定**(`src/lib/checks.js`, `src/lib/analyze.js`): 予測の的中(二項・片側)/交代率(二項)/最長の連(DPによる正確な分布)/3手パターン(NIST SP800-22 系列検定)/圧縮率(予測器での符号長、本物2000本とのモンテカルロ比較)/表の割合(二項)。
- **多重検定**: 6検定を Holm 法で補正し、補正後 p<0.05 のときだけ「本物と区別できる」と言う。補正前の値も並べる。
- 図はすべて「本物の乱数2000本ぶんの分布の山」と「あなたの位置」で統一。

## テストで固定していること

- i 手目の予測は i 手目以降を書き換えても変わらない(後出し不可)
- 本物の乱数 300人×200手では的中率が 50% から統計的にずれない
- 本物の乱数を誤って「区別できる」と判定する率は 5% 程度に収まる(補正なしだと増える)
- 交代しすぎる合成人間は 58% 以上当て、8割以上を見抜く
